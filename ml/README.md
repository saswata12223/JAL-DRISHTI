---

## 1. Purpose & Scope

The `ml/` module encapsulates the hydrometeorological modeling stack aligned with the FlashFloodAI Project PPT:
- **SCS-CN / HEC-HMS Physics Layer**: Potential maximum retention ($S$), initial abstraction ($I_a$), direct runoff depth ($Q$), and kinematic peak runoff wave potential dynamically adjusted via SMAP soil moisture.
- **Tree Ensembles**: Random Forest (Baseline), XGBoost (Champion), and LightGBM.
- **Deep Learning Sequence Modeling**: PyTorch Spatio-Temporal LSTM.
- **Spatial Graph Neural Networks**: PyTorch Geometric GCN message passing over geodetic catchment adjacency graphs.
- **Hybrid Spatio-Temporal Modeling**: Unified Hybrid GNN + Spatio-Temporal LSTM and Physics-Informed Hybrid GNN-LSTM.
- **Real-Time Inference Engine**: `ml.inference.FloodRiskInferenceEngine` computing physics parameters on-the-fly and outputting calibrated flood probabilities.

## 5. Programmatic Inference Usage (for Backend Integration)

```python
from ml.inference import FloodRiskInferenceEngine

# Initialize inference engine (loads XGBoost + SCS-CN physics layer)
engine = FloodRiskInferenceEngine()

# Predict risk for a feature dictionary
result = engine.predict_sample({
    "rainfall_30min_mm": 18.0,
    "rainfall_1h_mm": 35.0,
    "surface_soil_moisture_vol": 0.88,
    "profile_soil_moisture_vol": 0.85,
    "soil_saturation_index": 0.86,
    "elevation_m": 2200.0,
    "slope_deg": 30.0,
    "landcover_class": 10,
})

print(f"Risk Probability : {result['probability']:.4f}")
print(f"Risk Class       : {result['risk_class']}")  # 'EXTREME'
print(f"SCS Runoff Q     : {result['scs_direct_runoff_q_mm']:.2f} mm")
```
